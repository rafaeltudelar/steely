# Web

[← Início](../README.md)

Aplicação web do Steely: a experiência do usuário final no navegador e o painel de back-office (moderação, leilões, verificação de ONGs, DaaS).

| | |
|---|---|
| **Tecnologia** | React + Vite (SPA) · TanStack Query + Zustand |
| **Hospedagem** | Cloudflare Pages |
| **Captcha** | Cloudflare Turnstile |
